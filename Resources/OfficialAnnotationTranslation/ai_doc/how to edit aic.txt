
•	[key stream] // 按键名称（可省略）, 按键文件名
combo combo attack.key // 按键名称: combo, 索引: 0
AICharacter/cuwaki/key/a.key // 按键名称: a, 索引: 1
`` AICharacter/cuwaki/key/s.key // 按键名称: s, 索引: 2
[/key stream]
•	在 [key stream] 中列出按键名称和按键文件名。
•	按键名称可以省略，且不能以 ".key" 结尾。如果以 ".key" 结尾，则会被识别为按键文件名。
•	如果省略按键名称或输入 ``，则会从按键文件名中去除路径和扩展名，自动指定为按键名称。
•	按键名称会按顺序分配从 0 开始的索引。
•	按键名称和分配的索引会在 ai 文件中使用 [return] 时用到。
•	按键文件名可以输入去掉脚本路径的相对路径，或只输入文件名。
如果不输入路径，则会在 aic 文件所在目录的子目录 "key" 下寻找文件。
*** APC的队伍指定功能**
1.	在 aic 文件中指定固定队伍成员。
o	固定队伍成员的成员索引从 1 开始使用。
o	指定的固定队伍成员不会被更改。
o	固定队伍成员的数量限制实际上不存在。
指定方法)
[party member] // 成员索引, APC 索引
1 20402 // 1号是白虎
2 5004 // 2号是阿拉德的格斗家
3 605 // 3号是骨剑士杰诺
[/party member]
2.	自动注册：除非特别指定，否则自动注册。
o	0号指向自己。
o	按照 -1, -2, -3 号的顺序注册。
o	当队伍成员消失（死亡）时，为了填补空位，索引会重新分配。
o	自动注册队伍成员的数量限制实际上不存在。
3.	使用已注册队伍成员的方法
o	在 ai 文件中使用祭司队伍增益功能前指定队伍成员。
o	[set party member] {成员索引} : 指定增益技能目标队伍成员。
4.	相关的附加功能：在 ai 文件中使用
o	[party member alive] : 检查指定成员是否存活。
o	[party member hp] {比较} {数值} : 检查指定成员的 hp。
5.	使用示例：ai 文件
[think] [set party member] 2 // 指定注册在 2 号的队伍成员
[think] [party member alive]
[true]
[think] [party member hp] %> 50
[true] [return] a // 对 2 号队伍成员使用 a 槽中指定的快速治愈技能。
[false] [return] -1
[/think]
[false]
[return] -1
[/think]
[/think]

* Key 설정
- 사용 예:
[key stream]	// 키이름(생략가능), 키파일명
`combo`	`combo attack.key`	// 키이름 : `combo`, 인덱스 : 0
`AICharacter/cuwaki/key/a.key`	// 키이름 : `a`, 인덱스 : 1
``	`AICharacter/cuwaki/key/s.key`	// 키이름 : `s`, 인덱스 : 2
[/key stream]
	
- [key stream]에 키이름, 키파일명을 나열한다
- 키이름은 생략 가능하며, ".key"로 끝나면 안 된다. ".key"로 끝나면 키파일명으로 인식됨
- 키이름을 생략 하거나 ``로 입력하면 키파일명에서 경로와 확장자를 제거하고 키이름을 자동으로 지정합니다
- 키이름에는 순서대로 0부터 인덱스가 할당 됩니다
- 키이름과 할당된 인덱스은 ai파일에서 [return] 시 사용됩니다
- 키파일명은 스크립트 경로를 뺀 상대경로를 입력하거나, 경로를 뺀 파일명을 입력하면 됩니다.
	경로를 입력하지 않으면 aic파일이 있는 디렉토리의 서브디렉토리 "key" 아래에서 파일을 찾습니다.

* APC의 파티 지정 기능
1. aic파일에 고정 파티원을 지정한다
	- 고정 파티원의 멤버 인덱스는 1부터 사용한다
	- 지정된 고정 파티원은 변경되지 않는다
	- 고정 파티원 수 제한은 실질적으로 없습니다
지정방법)
	[party member]	// 멤버 인덱스, APC 인덱스
		1	20402		// 1번은 백호
		2	5004		// 2번은 아라드의 격투가
		3	605		// 3번은 뼈검사 제노
	[/party member]

2. 자동 등록 : 특별히 지정하지 않고 자동으로 등록된다
	- 0번은 자기 자신을 가리킵니다
	- -1, -2, -3번 순으로 등록됩니다
	- 파티원이 사라질 경우(죽었을 때), 빈 번호를 채워주기 위해 인덱스가 다시 할당됩니다
	- 자동 등록 파티원 수 제한은 실질적으로 없습니다

3. 등록된 파티원을 사용하는 방법
	- ai파일에서 프리스트 파티 버프 기능을 사용하기 전에 파티원을 지정한다
	- [set party member] {멤버 인덱스} : 버프 스킬 대상 파티원 지정

4. 연관된 추가 기능 : ai파일에서 사용
	- [party member alive] : 지정된 멤버가 살아있는지 여부를 체크
	- [party member hp] {비교} {수치} : 지정된 멤버의 hp를 체크

5. 사용 예 : ai파일
[think] [set party member] 2	// 2번에 등록된 파티원을 지정
	[think] [party member alive]
		[true]
			[think] [party member hp] `%>` 50
				[true] [return] `a`	// 2번 파티원에게 a슬롯에 지정된 패스트 힐 스킬을 사용한다.
				[false] [return] -1
			[/think]
		[false]
			[return] -1
	[/think]
[/think]

* APC의 패시브 오브젝트 생성 금지 기능.
1. aic파일에 패시브 오브젝트 인덱스를 지정한다.
지정방법

1	// 인덱스
1	// 인덱스

2. apc가 특정행동을 할 때 지정 오브젝트 대신 다른 오브젝트를 만들게 하기 위해서 사용한다.
