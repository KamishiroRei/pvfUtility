该文档记录了APC（自动玩家角色）功能添加及改进事项的历史。
开发人员在添加及改进功能时，请在文档最上方留下记录。

2008年7月2日 吴英旭
* APC的被动对象生成禁止功能。
1. 在aic文件中指定被动对象索引。
指定方法：
[limit passiveobject] 
1    // 索引
1    // 索引
....
[/limit passiveobject]

2. 用于在APC执行特定行为时，代替指定的对象而创建其他对象。

2007年10月25日 郑延五
* APC的组队指定功能
1. 在aic文件中指定固定队伍成员。
    - 固定队伍成员的成员索引从1开始使用。
    - 指定的固定队伍成员不可更改。
    - 固定队伍成员数量限制实际上没有限制。
指定方法：
    [party member]    // 成员索引，APC索引
        1    20402        // 1号是白虎
        2    5004        // 2号是阿拉德的格斗家
        3    605        // 3号是骨剑士杰诺
    [/party member]

2. 自动注册：在没有特别指定的情况下自动注册。
    - 0号指向自己。
    - 按-1, -2, -3号顺序注册。
    - 当队伍成员消失（死亡时），为填补空缺编号会重新分配索引。
    - 自动注册队伍成员数量限制实际上没有限制。

3. 使用已注册队伍成员的方法：
    - 在ai文件中使用牧师队伍增益功能前指定队伍成员。
    - [set party member] {成员索引}：指定增益技能的目标队伍成员。

4. 相关的附加功能：在ai文件中使用。
    - [party member alive]：检查指定成员是否存活。
    - [party member hp] {比较符} {数值}：检查指定成员的HP。

5. 使用示例：ai文件
[think] [set party member] 2    // 指定2号注册的队伍成员
    [think] [party member alive]
        [true]
            [think] [party member hp] `%>` 50
                [true] [return] `a`    // 对2号队伍成员使用a槽中指定的快速治愈技能。
                [false] [return] -1
            [/think]
        [false]
            [return] -1
    [/think]
[/think]

2007年10月23日 郑延五
    - 在ai文件中，可以使用[check skill on]来检查特定技能的开启/关闭状态。
    - 使用[check skill on]可以检查的技能列表，请参考"on off skill list.rtf"文件。
使用示例：
        [think] [check skill on] 52    // 检查杀意波动的开启/关闭状态
            [true]    // 如果杀意波动开启
                [return] `a`
            [false]    // 如果杀意波动关闭
                [return] `s`
        [/think]

2007年10月10日 郑延五
    - 添加了脚本key中调用其他key文件的功能。
使用方法：[import key] `key 文件名`
            [import key]可以在可以出现[input]的位置使用。
注意事项：注意无限循环。

    - 在key文件中添加概率开关功能。
使用方法：使用[switch]、[/switch]、[percent]。
使用示例：
        [switch]
            [percent] 50
            [import key] `a.key`
            [percent] 30
            [import key] `s.key`
            [percent] 20
            [exit]
        [/switch]
注意事项：在switch语句内部不能直接使用switch语句。如需在switch语句内部使用switch语句，请将文件分离，并使用[import key]。
          循环功能同样不能在循环内部使用循环。请使用[import key]。
          但是，在switch语句内部使用循环，或在循环内部使用switch语句是可以的。

    - 在key文件中添加强制退出功能。
使用方法：[exit]

2007年10月8日 郑延五
    - 添加了脚本ai中调用其他ai文件的功能。
使用方法：[import ai] `ai 文件名`
            [import ai]可以在可以出现[think]的位置使用。
注意事项：调用的ai文件与被调用的ai文件都必须具备ai文件的完整形式。
           注意无限循环（a.ai -> b.ai -> c.ai -> a.ai->b.ai ...）- APC加载后执行时陷入无限循环会导致宕机。
参考事项：调用的ai文件与被调用的ai文件分别独立加载，错误信息也会分别输出。
变更事项：ai文件开头的[ai pattern]可以删除。

개발자는 기능 추가 및 개선 시 문서의 가장 윗 부분에 기록을 남기도록 합니다

2008년 7월 2일 오영욱
* APC의 패시브 오브젝트 생성 금지 기능.
1. aic파일에 패시브 오브젝트 인덱스를 지정한다.
지정방법
[limit passiveobject] 
1	// 인덱스
1	// 인덱스
....
[/limit passiveobject]

2. apc가 특정행동을 할 때 지정 오브젝트 대신 다른 오브젝트를 만들게 하기 위해서 사용한다.

2007년 10월 25일 정연오
* APC의 파티 지정 기능
1. aic파일에 고정 파티원을 지정한다
	- 고정 파티원의 멤버 인덱스는 1부터 사용한다
	- 지정된 고정 파티원은 변경되지 않는다
	- 고정 파티원 수 제한은 실질적으로 없습니다
지정방법)
	[party member]	// 멤버 인덱스, APC 인덱스
		1	20402		// 1번은 백호
		2	5004		// 2번은 아라드의 격투가
		3	605		// 3번은 뼈검사 제노
	[/party member]

2. 자동 등록 : 특별히 지정하지 않고 자동으로 등록된다
	- 0번은 자기 자신을 가리킵니다
	- -1, -2, -3번 순으로 등록됩니다
	- 파티원이 사라질 경우(죽었을 때), 빈 번호를 채워주기 위해 인덱스가 다시 할당됩니다
	- 자동 등록 파티원 수 제한은 실질적으로 없습니다

3. 등록된 파티원을 사용하는 방법
	- ai파일에서 프리스트 파티 버프 기능을 사용하기 전에 파티원을 지정한다
	- [set party member] {멤버 인덱스} : 버프 스킬 대상 파티원 지정

4. 연관된 추가 기능 : ai파일에서 사용
	- [party member alive] : 지정된 멤버가 살아있는지 여부를 체크
	- [party member hp] {비교} {수치} : 지정된 멤버의 hp를 체크

5. 사용 예 : ai파일
[think] [set party member] 2	// 2번에 등록된 파티원을 지정
	[think] [party member alive]
		[true]
			[think] [party member hp] `%>` 50
				[true] [return] `a`	// 2번 파티원에게 a슬롯에 지정된 패스트 힐 스킬을 사용한다.
				[false] [return] -1
			[/think]
		[false]
			[return] -1
	[/think]
[/think]
