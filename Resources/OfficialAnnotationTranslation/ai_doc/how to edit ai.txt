1. * .ai 文件是什么？
这是用于编程决定AI角色行为的脚本。
虽然可以像用C语言编程一样进行编程，但要麻烦得多。
________________________________________
2. * .ai 文件的类型
.ai 文件根据用途进行区分。简单介绍如下：
2.1. Action.ai
用于执行攻击、增益等行为。
其返回值与 .aic 文件的 [key stream] 中指定的按键输入文件一一对应，用于执行这些按键。
2.2. DestinationSelect.ai
用于决定选择移动目的地的模式。
其返回值是代表预设[目的地决定模式]的数字。
（参考下文目的地决定方式对应的数字表）
•	详细信息请参考 destination select.rtf
2.3. Event.ai
用于决定发生某些事件时应采取何种行为。
其返回值与 .aic 文件的 [key stream] 中指定的按键输入文件一一对应，用于执行这些按键。
2.4. MoveMethod.ai
用于决定如何移动到目的地。
返回值决定了是跳跃移动、冲刺移动还是行走移动等。
（参考下文移动方法对应的数字表）

3. 条件变量介绍
输入条件变量时，可以省略 `。
3.1. [void] = 无输入
3.2. [mind] = 未实现
3.3. [hp] = 当前生命值
3.4. [mp] = 当前法力值
3.5. [warlike] = 好战性
3.6. [target distance] = 与当前目标的像素距离
3.7. [random] = 0 ~ 99 的随机值（持续变化！！）
3.8. [last result] = 最后一次运算结果（某些特定函数会向此赋值）
3.9. [weapon type] = 表示武器类型
melee = 鬼剑士, 格斗家, 祭司, 战斗法师 = 0
range = 枪手, 魔法师类 = 1
3.10. [target state] = 当前目标的状态（stand, sit, down, damage, jump 等）
各状态有对应的编号（参考下文状态数字表）
3.11. [state] = 当前自身状态（stand, sit, down, damage, jump 等）
各状态有对应的编号（参考下文状态数字表）
3.12. [event] = 事件类型（damage, attack 等）
各事件有对应的编号（参考下文事件数字表）
3.13. [attack success] = 攻击成功与否（攻击时 - Event.ai）
使用方法) [think] [attack success] 1
3.14. [hit] = 是否受到攻击（受到伤害时 - Event.ai）
使用方法) [think] [hit] 1
3.15. [element] = 攻击或受击的伤害属性（攻击或受击时 - Event.ai）
使用方法) [think] [element] 属性
3.16. [casting] = 是否使用吟唱技能（使用技能时 - Event.ai）
使用方法) [think] [casting] 1
3.17. [distance] = 检查与对方的距离（攻击或受击时 - Event.ai）
使用方法) [think] [distance] 距离
3.18. [my active status] = 检查自身状态变化（持续检查 - Action.ai）
使用方法) [think] [my active status] 状态变化
3.19. [my state] = 检查自身状态（持续检查 - Action.ai）
使用方法) [think] [my state] 状态
3.20. [target state] = 检查对方状态（攻击或受击时 - Event.ai, 持续检查 - Action.ai）
使用方法) [think] [target state] 状态
3.21. [my active status on] = 检查自身状态变化（仅在状态变化时 - Event.ai）
使用方法) [think] [my active status on] 状态变化
3.22. [target active status] = 检查对方状态变化（攻击或受击时 - Event.ai）
使用方法) [think] [target active status] 状态变化
3.23. [attack type] = 检查自身攻击形态（攻击或受击时 - Event.ai）
使用方法) [think] [attack type] 类型
3.24. [target type] = 检查对方攻击形态（攻击或受击时 - Event.ai）
使用方法) [think] [target type] 类型
3.25. [attack condition] = 检查自身攻击命中条件（攻击或受击时 - Event.ai）
使用方法) [think] [attack condition] 命中条件
3.26. [use skill] = 检查是否使用特定技能（使用技能时 - Event.ai）
使用方法) [think] [use skill] 技能索引
3.27. [stat change] = 比较HP或MP（持续检查 - Action.ai）
使用方法) [think] [stat change] [hp/mp] 比较方式 数值
3.28. [cooltime] = 指定冷却时间（若指定则应用 - Action.ai, Event.ai）
使用方法) [think] [cooltime] 数值
[true] [return] 1
•	当 [true] 中的 [return] 生效时，[cooltime] 被应用。
•	[cooltime] 必须在紧邻 [return] 之前的 [think] 中定义才能生效。
3.29. [my death] = 检查自身是否死亡（自身死亡时 - Event.ai）
使用方法) [think] [my death] 1
3.30. [target death] = 检查对方是否死亡（对方死亡时 - Event.ai）
使用方法) [think] [target death] 1
3.31. [revive] = 检查自身是否复活（自身复活时 - Event.ai）
使用方法) [think] [revive] 1
3.32. [combo] = 比较连击数（攻击时 - Event.ai）
使用方法) [think] [combo] 比较方式 数值
3.33. [aerial] = 比较空中连击数（攻击时 - Event.ai）
使用方法) [think] [aerial] 比较方式 数值
3.34. [overkill] = 检查对方是否被overkill杀死（对方死亡时 - Event.ai）
使用方法) [think] [overkill] 1
3.35. [set friend character] = 设置友军角色（DestinationSelect.ai）
使用方法) [set friend character] {AI角色编号}
3.36. [set target monster] = 设置目标怪物（DestinationSelect.ai）
使用方法) [set target monster] {怪物编号} {团队(enemy or neutral or friend)}
3.37. [set friend object] = 设置友军对象（DestinationSelect.ai）
使用方法) [set friend object] {对象编号}
3.38. [set bound] = 指定APC的移动范围（DestinationSelect.ai）
使用方法) [set bound] {前方视野距离} {后方视野距离} {上方视野距离} {下方视野距离}
3.39. [auto attack direction] = 设置按键输入时APC是否自动面向敌人方向
默认值为1，且功能被关闭
使用方法) [auto attack direction] {1 or 0}
3.40. [my attack] = 攻击时检查APC的技能
使用方法) [my attack] {技能编号}
3.41 [my hp down] = 检查HP减少的瞬间
使用方法) [my hp down] {+ or %} {数值}
使用例) [my hp down] % 90
3.41 [my mp down] = 检查MP减少的瞬间
使用方法) [my mp down] {+ or %} {数值}
3.42 [check use skill] = 检查是否可以使用特定技能
使用方法) [check use skill] {技能编号}
3.43 [check skill on] = 可以检查特定技能的开启/关闭状态
•	可使用 [check skill on] 检查的技能列表请参考 "on off skill list.rtf" 文件
使用方法) [check skill on] {技能编号}
使用例) [think] [check skill on] 52 // 检查杀意波动的开启/关闭状态
[true] // 如果杀意波动开启
[return] a
[false] // 如果杀意波动关闭
[return] s
[/think]

4. 运算函数介绍
>=
例) [hp] >= 1000.0
当前生命值大于或等于1000则为 true
%>=
说明) 用于判断当前值与最大值之比的百分比是否大于条件值。
例) [hp] %>= 20.0
当前生命值大于或等于最大生命值的20%则为 true
==
例) [hp] == 99.0
当前生命值等于99则为 true
%== （百分比等于）
> （大于）
%> （百分比大于）
<= （小于等于）
%<= （百分比小于等于）
< （小于）
%< （百分比小于）
check random()
说明) 进行随机概率检查。
例) [void] check random() 30.0 100.0
30%概率为 true
check bonus random()
说明) 在成功概率上加上指定的奖励值后进行随机概率检查。
例) [warlike] check bonus random() 30.0 100.0
30 + 好战性 的概率为 true
is in range()
例) [hp] is in range() 100.0 500.0
当前生命值大于等于100且小于等于500则为 true
get random()
例) [void] get random() 0.0 100.0
向 [last result] 填入一个0~99的随机值。
is target in attack area()
例) [void] is target in attack area() 100.0(前) 15.0(后) 50.0(上) 50.0(下)
当前目标位于指定的前、后、上、下区域内则为 true
enemy number of in attack area()
例) [void] enemy number of attack area() 100.0(前) 15.0(后) 50.0(上) 50.0(下)
位于指定前、后、上、下区域内的敌人数量会填入 [last result]。
is the skill in cooltime()
例) [void] is the skill in cooltime() 46.0
如果46号技能正在冷却中则为 true
number of in attack area()
使用方法) [void] number of in attack area() {前} {后} {上} {下} {enemy/neutral/friend/all} {monster/character/apc/passive object/summon/all} {索引(-1则不检查) or 名称}
索引或名称，如果是 character 则可以输入职业（职业名请参考 OperatingValue.lst）
is target object in area()
*在指定范围或全地图内寻找目标
使用方法)
[void] is target object in area() {是否使用范围检查} {前} {后} {上} {下} {索引} {选择方式}
*是否使用范围检查输入1或0。为1时，参考后面的前、后、上、下值，寻找范围内的索引对象。为0时在全地图寻找。
*选择方式有 0:默认 1:最近 2:随机。0为不考虑距离，找到的第一个；1为最近的；2为随机。

1. * .ai 이것은 무엇인가?

ai캐릭터가 어떤 행동을 할지 결정하도록 프로그래밍하는 스크립트이다.

마치 c언어로 프로그래밍 하는 것과 비슷하게 프로그래밍이 가능하다. (물론 훨씬 많이 불편하지만 -_-)

2. * .ai 의 종류

.ai 파일은 용도별로 나누어져있습니다. 간단히 소개하겠습니다.

  2.1. Action.ai
	이것은 공격, 버프 등의 행위를 시키기 위해서 사용됩니다.
	이것의 리턴값은 .aic (AI C haracter) 파일의
	[key stream] 에 지정된 키입력파일들과 1:1 로 매칭되어 그것을 실행하는데 사용됩니다.

  2.2. DestinationSelect.ai
	이것은 이동할 목적지를 고르는 패턴을 결정하기 위해서 사용됩니다.
	이것의 리턴값은 미리코딩되어있는 [목적지결정패턴] 을 나타내는 숫자입니다.
	(하단 목적지결정방법 별 숫자표 참조)
		- 상세한 내용은 `destination select.rtf`를 참조하세요

  2.3. Event.ai
	이것은 어떤 이벤트가 일어났을때 어떤 행동을 할지 결정하기 위해서 사용됩니다.
	이것의 리턴값은 .aic (AI C haracter) 파일의
	[key stream] 에 지정된 키입력파일들과 1:1 로 매칭되어 그것을 실행하는데 사용됩니다.

  2.4. MoveMethod.ai
	이것은 목적지로 이동할때 어떻게 이동할지 고르기 위해 사용됩니다.
	리턴값은 점프하면서 갈지, 대쉬로 갈지, 걸어갈지 등을 결정합니다.
	(하단 이동방법 별 숫자표 참조)

3. 조건변수들의 소개
조건 변수를 입력할 때 `는 생략 가능합니다

3.1. `[void]`	    = 입력이 없음
3.2. `[mind]`	    = 미구현
3.3. `[hp]`		    = 현재의 체력
3.4. `[mp]`		    = 현재의 마력
3.5. `[warlike]`	    = 호전성
3.6. `[target distance]` = 현재 타겟과의 픽셀거리
3.7. `[random]`	    = 0 ~ 99 까지의 랜덤값 (계속 바뀜!!)
3.8. `[last result]`	    = 마지막 연산결과 (몇몇 특정한 함수들이 여기로 값을 넣어준다.)
3.9. `[weapon type]`	    = 무기의 종류 를 나타낸다.
		      melee = 귀검, 격가, 프리스트, 배틀메이지 = 0
		      range = 거너, 마법사류 = 1

3.10. `[target state]` = 현재 타겟의 상태 (stand, sit, down, damage, jump 등등)
		   상태마다 정해진 번호가 있음 (하단의 상태별 숫자표 참조)

3.11. `[state]`	 = 현재의 상태 (stand, sit, down, damage, jump 등등)
		   상태마다 정해진 번호가 있음 (하단의 상태별 숫자표 참조)

3.12. `[event]`	 = 이벤트의 종류 (damage, attack 등)
		   상태마다 정해진 번호가 있음 (하단의 이벤트별 숫자표 참조)

3.13. `[attack success]` = 공격 성공 여부(공격 시 - Event.ai)
사용방법) [think] [attack success] 1

3.14. `[hit]` = 피격 당했는지의 여부(데미지 입을 때 - Event.ai)
사용방법) [think] [hit] 1

3.15. `[element]` = 맞거나 때린 데이지의 속성(공격이나 데미지 입을 때 - Event.ai)
사용방법) [think] [element] `속성`

3.16. `[casting]` = 캐스트 스킬 사용 여부(스킬 사용시 - Event.ai)
사용방법) [think] [casting] 1

3.17. `[distance]` = 상대방과의 거리 체크(공격이나 데미지 입을 때 - Event.ai)
사용방법) [think] [distance] `거리`

3.18. `[my active status]` = 내 상태 변화를 체크(지속적으로 - Action.ai)
사용방법) [think] [my active status] `상태변화`

3.19. `[my state]` = 내 상태를 체크(지속적으로 - Action.ai)
사용방법) [think] [my state] `상태`

4. 연산 함수들의 소개


`>=`
예) `[hp]` `>=` 1000.0
    현재 체력이 1000 보다 크거나 같으면 true

`%>=`
설명) 현재치와 최대치로 입력되는 조건값의 경우 %로 큰지 알아내는데 사용한다.
  예) `[hp]` `%>=` 20.0
      현재체력이 최대체력의 20% 보다 크거나 같으면 true

`==`
예) `[hp]` `==` 99.0
    현재 체력이 99 와 같으면 true

`%==`

`>`

`%>`

`<=`

`%<=`

`<`

`%<`

`check random()`
설명) 랜덤한 확율체크를 한다.
  예) `[void]` `check random()` 30.0 100.0
      30% 확율로 true

`check bonus random()`
설명) 성공확율에 지정한 보너스를 더하여 랜덤한 확율체크를 한다.
  예) `[warlike]` `check bonus random()` 30.0 100.0
      30 + 호전성의 확율로 true

`is in range()`
예) `[hp]` `is in range()` 100.0 500.0
    현재 체력이 100 보다 같거나 크고 500.0 보다 작거나 같으면 true

`get random()`
예) `[void]` `get random()` 0.0 100.0
    [last result] 에 0 ~ 99 까지의 랜덤값을 집어넣는다.

`is target in attack area()`
예) `[void]` `is target in attack area()` 100.0(앞) 15.0(뒤) 50.0(위) 50.0(아래)
    현재 타겟이 앞, 뒤, 위, 아래 로 지정한 영역에 있으면 true

`enemy number of in attack area()`
예) `[void]` `enemy number of in attack area()` 100.0(앞) 15.0(뒤) 50.0(위) 50.0(아래)
    앞, 뒤, 위, 아래 로 지정한 영역에 있는 적들의 숫자가 [last result] 에 들어감.

`is the skill in cooltime()`
예) `[void]` `is the skill in cooltime()` 46.0
    46번 스킬이 현재 쿨타임중이라면 true

`number of in attack area()`
사용방법) [void] `number of in attack area()`  {앞} {뒤} {위} {아래} {`enemy`/`neutral`/`friend`/`all`} {`monster`/`character`/`apc`/`passive object`/`summon`/`all`} {인덱스(-1이면 체크안함) or 이름}
인덱스나 이름은 `character`일 경우에는 직업을 쓰면 됩니다(직업명은 OperatingValue.lst 참고)

 'is target object in area()'
 *지정된 범위 혹은 맵 전체에 있는 타겟을 지정한다
사용방법)
[void] `is target object in area()` {범위체크 사용 유무} {앞} {뒤} {위} {아래} {인덱스} {선택방법}
 *범위체크 사용 유무는 1과 0중 하나를 입력 받습니다. 1일 경우 뒤의 앞,뒤,위,아래의 값을 참고하여 범위안의 인덱스 오브젝트를 찾습니다. 0일경우 맵 전체에서 찾습니다.
 *선택방법은 0:디폴트 1:가까운거 2:랜덤 입니다. 0은 거리와 상관없이 먼저 찾아진거,1은 가까운것,2는 랜덤입니다.

		`[true]` `[return]` -1			// 아무것도 안함

					`[false]` `[return]` 3			// 피폭

				`[true]` `[return]` 3			// 3 번 키입력 실행 - 피폭발

				`[false]` // 2마리라면
					`[think]` `[void]` `get random()` 0.0 100.0
						`[think]` `[last result]` `>=` 50.0	// 50% 확율로
						`[true]` `[return]` 1			// 0 번 키입력 실행 - 어퍼슬래쉬
						`[false]` `[return]` 2			// 1 번 키입력 실행 - 귀참

[/ai pattern]
