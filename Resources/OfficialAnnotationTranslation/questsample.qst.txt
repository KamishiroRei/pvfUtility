// 任务脚本示例

[grade] `[epic]` // 任务的等级。可选择 `[normaly repeat]` `[common unique]` `[epic]` `[achievement]` `[daily]` `[training]` `[title]` 之一。
[job change quest] 0 // 是否为转职任务。(0:一般, 1:转职, 2:觉醒, 10:使魔进化, 20:副职业)
[npc index] 0 // 该NPC的索引。
[complete npc index] 0 // 完成任务给的NPC索引。若为-1或未指定，则与[npc index]相同。

[exposed by npc] 0 // 是否由NPC暴露。1: 暴露, 0 : 不暴露，默认为1（若没有则取默认值）。
[event] 1 // 是否为活动任务。值为1时，拥有任务标记暴露的最高优先级，并变为活动任务标记。

[searching infomation] 0 // 默认为1。指定为0，则在小地图上不显示该任务在何处执行。

// 出现条件
[job] `[swordman]` // 可接受任务的职业。可选择 `[swordman]` `[fighter]` `[gunner]` `[priest]` `[mage]` `[at gunner]` `[thief]` `[all]` 之一。
[grow type] -1 // 可行的成长类型。无限制则为-1。
[exceptional grow type] // 排除的成长类型。若不排除则不写。 // 未使用
0
3
4
[/exceptional grow type]

[target character] // 可重复的job, grow type标签。顺序为职业，转职，觉醒。
`[swordman]` 1 -1 // 是上述标签[job]和[grow type]、[exceptional grow type]的合并形式，
`[at gunner]` 2 1 // 仅此一个标签即可替代，并可同时设置多个职业的条件。
[/target character]

[level] 3 99 // 可行的等级下限和上限。下限以上，上限以下可行（上限目前不生效）。
[ignore quest level 4 exp] 1 // 1:经验值金币奖励不跟随任务等级，而是跟随角色等级。任务标题始终保持橙色。

// 若不存在该标签，则默认为0。

// 任务带来的影响。
[effect after clear quest] 0 // 任务完成后是否对之后有影响。(1:有, 0:无)。
[delete npc index] 3 // 任务执行期间从地图上消失的NPC索引，若无则删除此项或设为-1。

[/monster reward item]

[enemy reward item] // 任务执行状态下杀死敌人（怪物、APC）时出现的任务物品。
50 1 1 0 10001 2 30 3 // 敌人索引，敌人类型(1:怪物, 2: APC, 3:obj(未实现))，地城索引（若无关则为-1），地城难度（若无关则为-1），物品索引，
51 1 2 0 10002 3 30 6 // 最大物品数，出现概率(%)，最大持有数（-1则为无限）。
[/enemy reward item]

// 任务完成条件。
[type] `[seeking]` // 任务的类型。可选择 `[seeking]` `[condition under clear]` `[hunt monster]` `[hunt enemy]` `[clear map]` `[meet npc]` `[pvp rank]` `[powerwar win]` `[powerwar point]` 之一。
[sub type] 0 // 任务的子类型。

[multi type]
`[clear map]`
`[meet npc]`
[/multi type]

38 3
29 2

// 地城信息。
[dungeon info] // 任务窗口中显示的地城目的地。也用作地城排序的依据。基本上参考seeking, condition under clear, hunt monster等的信息，因此大多数任务无需输入。
38 3 // 但，条件是clear map的情况下必须输入，seeking的情况下若判断需要也输入。可复数输入。（会复数显示）。
29 2 // 按地城索引，难度顺序输入。难度为-1则不显示难度。(-1,0,1,2,3,4顺序)地城索引参考dungeon文件夹内的dungeon.lst。
[/dungeon info] // 条件是meet npc的情况下，若后续任务要去地城，则meet npc的情况也输入地城信息。（例：洛兰>赛丽亚>格兰之森顺序，则在洛兰、赛丽亚任务中输入格兰之森地城信息）。

// 任务奖励。
[reward type] `[item]` // 奖励的类型。可选择 `[item]` `[grow type]` `[awakening type]` `[pro job]` `[hero]` 之一。
[reward int data] // 奖励的整数资料。用法参考最底部的注释。
10 1 // 若为`[hero]`则是[地城索引]。
2354 10
2356 `[job]` 2 1 10 // 在物品索引和数量之间添加`[job]`和职业索引、转职索引，则仅在该职业、转职时给予奖励。（若转职为-1则所有转职）。
[/reward int data] // 闭合。
[reward selection int data] // 奖励的整数资料。用法参考最底部的注释。
10 1
2354 10
2356 `[job]` 2 10 // 在物品索引和数量之间添加`[job]`和职业索引，则仅在该职业时可以选择该物品。
[/reward selection int data] // 闭合。
[relation quest] 4 // 任务完成后自动获得的任务。若为-1或标签不存在则为无。

[auto display] [0]出现条件 [1]出现详细条件 [2]消失的条件（以数字表示的等级范围） // 建议不使用。
// [0]出现条件 [1]出现详细条件 [2]消失的条件（-1则为始终允许）。
// 0 : 进入特定城镇时 城镇索引 允许等级范围。
// 1 : 经过特定NPC前时 NPC索引 允许等级范围。

[change dungeon info message] `请在此输入信息` // 可以指定鼠标悬停在任务上时弹出的提示文本。

// 子类型与整数资料用法
//
// `[seeking]`
// [子类型] : 注意！！！：仅在稀有度检查模式时才需要填写子类型！
///
/// -1. 所有装扮
/// 0 帽子装扮
/// 1 头发装扮
/// 2 脸部装扮
/// 3 上衣装扮
/// 4 下装装扮
/// 5 鞋子装扮
/// 6 颈部胸部装扮
/// 7 腰部装扮
/// 8 肤色装扮
/// 9 光环装扮
/// 10 武器
/// 11 称号
/// 12 上衣
/// 13 护肩
/// 14 下装
/// 15 鞋子
/// 16 腰带
/// 17 项链
/// 18 手镯
/// 19 戒指
/// 20 辅助装备
/// 21 魔法石
/// 22 宠物
//
// [int data] : 交替写下需要寻找的物品索引和该物品的数量。
// : 若想按稀有度检查，请参考以下类别。
// 0. 普通 : -1
// 高级 : -2
// 稀有 : -3
// 神器 : -4
// 史诗 : -5
// 传说 : -6
// 全部 : -7
//
//
// `[condition under clear]` - 若难度无关，则难度为-1。
// [子类型] : 0 : 时间限制内通关。
// 1 : 累计受击数在一定数量以下。
// 2 : 技巧分数在一定数量以上。
// 3 : 风格分数在一定数量以上。
// 4 : 未使用复活币通关。
// 5 : 以一定队伍人数通关（通关时为准）。
// 6 : 直接通关。
// 7 : 获得特定连招评分。
// 8 : 达成一定次数以上的背后攻击。
// 9 : 达成一定次数以上的反击。
// 10 : 达成最大连击次数一定以上。
// 11 : 通关一定数量以上的地图。
// 12 : 技能使用次数限制。
// 13 : 消耗品使用限制。
// 14 : 材料使用限制（主要是无色小晶块）。
// 15 : 多重攻击次数使用限制。
// 16 : 被动对象破坏数限制。
//
// [int data] : 0 : [0]地城索引 [1]地城难度 [2]最大通关时间（秒）。
// 1 : [0]地城索引 [1]地城难度 [2]最大受击数。
// 2 : [0]地城索引 [1]地城难度 [2]最低技巧分数（%）。
// 3 : [0]地城索引 [1]地城难度 [2]最低风格分数（%）。
// 4 : [0]地城索引 [1]地城难度。
// 5 : [0]地城索引 [1]地城难度 [2]队伍人数。
// 6 : [0]地城索引 [1]地城难度。
// 7 : [0]地城索引 [1]地城难度 [2]最低连招评分（原有数值。目前无意义 - SSS:105 SS:95 S:85 A:70 B:55 C:45 D:40 E:35 F:0）。
// 8 : [0]地城索引 [1]地城难度 [2]最低背后攻击成功次数。
// 9 : [0]地城索引 [1]地城难度 [2]最低反击成功次数。
// 10 : [0]地城索引 [1]地城难度 [2]需达成的最大连击次数。
// 11 : [0]地城索引 [1]地城难度 [2]需要通关的地图数量。
// 12 : [0]地城索引 [1]地城难度 [2]技能索引（需要注意按角色区分）[3]最少使用次数（0或-1则视为不使用）。
// 13 : [0]地城索引 [1]地城难度 [2]物品索引（0或-1则为所有消耗品）[4]使用限制次数（0或-1则视为不使用），若使用负数则表示必须使用才能通关。
// 14 : [0]地城索引 [1]地城难度 [2]物品索引（0或-1则为所有材料）[4]使用限制次数（0或-1则视为不使用），若使用负数则表示必须使用才能通关。
// 15 : [0]地城索引 [1]地城难度 [2]一次需攻击的最小怪物数（0或-1则与怪物数无关）[4]成功次数（0或-1则视为1次）。
// 16 : [0]地城索引 [1]地城难度 [2]对象索引（0或-1则为任何对象）[4]限制数量（0或-1则表示一个也不破坏通关）。
//
// `[hunt monster]` - 若与地城无关则地城索引为-1，若与地城难度无关则地城难度为-1。
// [子类型] : 未使用。
// [int data] : [0]地城索引 [1]地城难度 [2]怪物索引 [3]需击杀数量。
// * [2] -1 : 所有普通怪物，-2 : 所有稀有怪物，-3 : 所有首领怪物，-11 : 所有稀有 & 首领怪物。
//
// `[hunt enemy]` - 若与地城无关则地城索引为-1，若与地城难度无关则地城难度为-1。
// [子类型] : 未使用。
// [int data] : [0]地城索引 [1]地城难度 [2]敌人索引 [3]敌人类型(1:怪物, 2: APC, 3:对象, 10 : 所有主动对象) [4]需击杀数量。
// * [2] -1 : 所有普通敌人，-2 : 所有稀有敌人（APC无稀有），-3 : 所有首领敌人，-11 : 所有稀有 & 首领敌人。
//
// `[clear map]`
// [子类型] : -1 : 普通地图通关。
// 0 : APC同行任务。
// [int data] : -1 : [0]需通关的地图索引。
// 0 : [0]需通关的地图索引 [1]同行的APC索引。
// ※ 注意：APC同行的情况下，必须在利用此任务索引的该地城的任务迷宫中包含此APC出现的地图。
//
// `[meet npc]`
// [子类型] : 未使用。
// [int data] : [0]需会见的NPC索引。
//
// `[pvp rank]`
// [子类型] : 未使用。
// [int data] : [0]要求的PVP等级。
// 0:蛋 1:9级 2:8级 3:7级 4:6级 5:5级 6:4级 7:3级 8:2级 9:1级
// 10:1段 11:2段 12:3段 13:4段 14:5段 15:6段 16:7段 17:8段 18:9段 19:10段
// 20:至尊1 21:至尊2 22:至尊3 23:至尊4 24:至尊5 25:至尊6 26:至尊7 27:至尊8 28:至尊9 29:至尊10
// 30:达人 31:名人 32:小霸王 33:霸王 34:斗神

// : 若我所属势力在势力战中获胜，则完成的条件。
// [子类型] : 未使用。
// [int data] : 未使用。
//
// `[powerwar point]`
// [子类型] : 未使用。
// [int data] : [0]要求的势力战点数。
//
//
// * 因成就系统开发而增加的任务类型。

// 3037 1 // 无色，使用1个时条件满足。
